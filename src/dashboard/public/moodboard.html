What's inside

Five moods. One ritual.

🎨

Wallpaper per mood

Pick any photo from disk or fall back to a mood-tinted gradient. Running a mode applies the wallpaper to every connected display immediately.

🎵

Your media queue

Add MP4, MOV, MP3, M4A, M4B — they play one after another. Duration is read from the file. Broken files are skipped. Video plays on the main display only for stability.

✍️

Streamed text

A phrase types itself out letter by letter over the overlay. You edit the text per mode. Arabic phrases display with full right-to-left layout.

〰️

Live wave animation

Audio-only tracks (MP3, M4B…) get an animated sound-wave overlay that tracks with playback position. Visual feedback without video.

⏱

Time readout

Elapsed / total time and a progress capsule for each track. When the last item finishes, the overlay closes itself. Or tap Dismiss now anytime.

🔒

Private, local

File paths stored with macOS bookmarks on your machine. No accounts, no analytics, nothing uploaded. MoodBoard doesn't touch your battery or SMC.

How it works

One tap to shift the room

01

Open MoodBoard from the menu bar

Tiny icon in your menu bar. Click to open the control panel — pick a mode.

02

Set wallpaper + media per mode

Drag a photo or pick from disk. Add MP4/MP3 files to the queue for that mode. Edit the streamed phrase.

03

Tap Run mode

Wallpaper updates on all screens. The dim overlay opens. Your phrase types itself out.

04

Media plays with time + waves

Queue plays in order. Live elapsed/total timer. Wave animation for audio tracks. Video on main display.

05

Overlay closes when done (or you dismiss it)

Last item finishes → overlay closes on its own. Or hit Dismiss now to close early.
