About the data

The zone temperatures shown are illustrative — driven by system thermal state + light animation, not certified hardware readings. For deep telemetry, pair with dedicated diagnostics tools. ThermalMap is designed for quick visual feedback, not precision monitoring.

What's inside

Current features

Everything below ships in the downloaded build — ready on first launch.

THERMAL

System Thermal State

Displays Apple's ProcessInfo thermal state — from Nominal to Critical — with plain-language guidance on what each state means for your workflow.

ZONES

6 Thermal Zones

Visual zone map covering CPU, GPU, Neural Engine, storage, battery, and chassis. Each zone shows relative "heat" scaled from the system state.

MENU

Menu Bar Panel

Compact menu bar utility that opens a summary panel. Quick access to the full dashboard, settings, and quit — all from the menu bar icon.

FAN

Animated Fan Indicator

Live spinning fan visualization that responds to thermal load. Watch your Mac's cooling system in action with smooth CSS animations.
