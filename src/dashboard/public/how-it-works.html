OpenHands (optional Docker sandbox) is used by the implementer agents for real clones and tests. The voice meeting page uses Jitsi for humans and Socket.IO on the dashboard port for the shared AI thread.

Task flow

From /plan to merge request

The branch plan.branch is the task branch everywhere: clone, push, MR source.

Plan

User sends /plan with a task; Planner analyzes the repo (MCP or GitLab API) and returns steps, files, and plan.branch.

Approve

User sends /approve. Orchestrator sets task.branch = plan.branch and selects Frontend vs Backend Dev from primaryStack.

Implement

Backend Dev may use OpenHands (clone, edit, push) or generate code and repo-clone-push. Frontend Dev uses clone/push with generated UI code.

Verify & ship

QA runs tests where possible; Code Reviewer diffs task branch vs default. Orchestrator opens an MR: plan.branch → default branch.

Workflow Studio

Canvas, meeting, voice room

In the dashboard, Workflow Studio stores projects in data/workflow-projects.json. Roundtable chat uses the same engine as the public meeting page.

Studio & GitLab

Link a GitLab path, drag agent nodes, connect ports. AI draft suggests a layout from the repo tree. Save updates the JSON project file.

  • GET /api/gitlab/repos — repository list
  • POST /api/workflow-projects/draft-from-repo — AI layout

Voice meeting

Shareable link creates a session token. meeting-room.html?token= loads Jitsi plus Socket.IO events join-meeting, meeting-sync, meeting-roundtable for a shared AI transcript.

  • HTTPS required for mic + Web Speech in production
  • EC2 / nginx / Socket.IO (repo doc)
