Import bugs from Excel

Upload .xls or .xlsx. The importer picks the first worksheet whose header row includes Title (matches exports like Bonyad_BUGS.xlsx: Module, Type, Priority, Title, Description, Steps to Reproduce, Expected / Actual Behavior, Notes, Attachments, Status). Hyperlinks on a row (e.g. screenshot cell linking to a URL) are read as the real https target for clickable bugs, not only the visible filename. Plain http(s) text in cells is detected too. Status solved marks the issue done. No edit key required — up to 2000 rows, 6 MB max. If you import into the wrong sheet, use Undo last import (same browser tab) to delete only the rows that import just added.
