AI features — roadmap & collaboration

Planned and in-flight capabilities that use automation and AI around Bonyad fix briefs, Nigents agents, and delivery. Each item lists priority, what it is, how we intend to use it, dependencies, and who we should work with.

Priority — P0

Excel → Bonyad bulk import

Upload .xls / .xlsx on the Bonyad hub; the first worksheet is parsed and rows become issues on the chosen sheet (title, description, optional priority, tags, acceptance criteria).

How to

Open Bonyad hub → Import bugs from Excel, pick the target platform sheet, choose a file, and submit. No server edit key is required; limits apply (row count and file size).

What we need

MySQL-enabled Nigents dashboard; xlsx + multer on the server; agreed column naming for PMs (documented on the hub).

Collaborate with

Project managers and QA (spreadsheet owners); devops for deploy and env checks.

Priority — P1

Natural-language issue drafting

Paste meeting notes or a paragraph; an LLM proposes titled issues with prompts and acceptance criteria in Bonyad shape for human review before save.

How to

Future UI: “Draft from text” on the sheet page → model output as a preview list → user edits → bulk create with existing edit key.

What we need

API keys / gateway policy; prompt templates and guardrails; rate limits; audit logging of generated content.

Collaborate with

Product for UX copy and review flow; security / legal for data handling; model provider or internal LLM team.

Priority — P1

GitLab-aware issue linking

Connect issues to GitLab issues, MRs, or branches so status and links stay visible on the fix brief.

How to

Store GitLab URLs or IDs on issues; optional webhook or poll to reflect MR merge state; surface links on sheet.html.

What we need

GitLab token scopes; schema fields on bonyad_issues; UI for paste/validate URL.

Collaborate with

Engineering leads (workflow); GitLab admins (tokens, hooks).

Priority — P2

Transcript → structured bugs

Ingest standup or client call transcripts; segment into candidate bugs with owners and priorities suggested by the model.

How to

Upload or paste transcript; async job returns proposed rows; user maps to sheet and edits.

What we need

ASR integration if starting from audio; chunking + citation to transcript lines; privacy classification (PII redaction).

Collaborate with

PMO and client-facing teams; compliance if recordings are stored.

Priority — P2

Regression hints from code change

Given a diff or MR summary, suggest related Bonyad issues to re-test or new criteria to add — advisory only.

How to

Nigents or dashboard calls search + LLM over issue titles/prompts; output checklist for QA.

What we need

Indexed issue text; MR/diff access; clear “suggestions not approvals” UX.

Collaborate with

QA leads; backend team for GitLab integration depth.
