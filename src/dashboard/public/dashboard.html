Build · connect · ship
Workflow Studio

Map agents to a GitLab repo. AI analyzes the codebase and drafts a flow; edit, connect, and save. With MySQL, graphs are stored in the database (and seeded per repo on first run); the Live run panel streams code, shell, and agent messages while tasks execute.

AI analysis

Manual: drag agents from the palette onto the canvas. Connect: drag from the orange output dot on one card to the gray input dot on another — edges define handoffs; the orchestrator passes structured context between agents at runtime. Duplicate roles: AI may add when the repo warrants it (see text on the card).

Live run

When a task is running on the linked repo (from Telegram or this dashboard), code edits, shell lines, agent-to-agent messages, and status stream here. The active agent card glows on the canvas.
