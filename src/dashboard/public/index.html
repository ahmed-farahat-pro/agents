Everything You Need to Ship Faster

A complete AI development team with self-healing, parallel execution, and intelligent cost optimization.

Core

Parallel Execution

Backend and frontend agents work simultaneously on fullstack tasks. Code reviews run security, quality, and RTL checks in parallel.

Core

Self-Healing Workflows

Compile failures trigger automatic fix-and-retry cycles. Provider fallback chains ensure AI calls never silently fail.

New

Security Scanning

Dedicated security agent scans for secrets, OWASP Top 10 vulnerabilities, and dependency CVEs. Blocks MRs on critical findings.

New

Agent Memory

Cross-task learning with LRU eviction. Agents remember codebase structure, recurring issues, and compile-fix patterns.

New

Cost Optimization

Smart model selection based on task complexity. Trivial tasks use cheaper models, complex tasks get premium AI with budget tracking.

New

Agent Communication Bus

Pub/sub event system for inter-agent messaging. Agents share findings laterally instead of routing through the orchestrator.

Core

GitLab Integration

Automatic branch creation, commits, and merge requests. Pipeline monitoring and deployment readiness checks built in.

Core

Telegram Control

Send voice or text commands from anywhere. Get real-time progress updates and results in Arabic or English.

Core

Multi-Model AI

Provider fallback chains across GLM, Kimi, DeepSeek, and Anthropic. Automatic failover ensures zero downtime.

Latest Enhancements

01

Testing Infrastructure

Built from scratch with Jest. 139 tests covering BaseAgent, Planner, Code Reviewer, QA Tester, Reporter, and all new utilities.

7 test suites -- 139 passing

02

Parallel Executor

Concurrency-controlled task runner. Backend and frontend agents now work simultaneously on fullstack implementations.

src/utils/parallel-executor.js

03

Self-Healing Workflows

Compile failures trigger automatic fix-and-retry cycles (up to 2 attempts). Provider fallback chains across all agents.

Orchestrator + BaseAgent enhanced

04

Agent Communication Bus

Singleton pub/sub EventEmitter for inter-agent messaging. Subscribe, publish, sendDirect, broadcast with message logging.

src/utils/agent-bus.js

05

Cross-Task Agent Memory

Persistent learning with LRU eviction and relevance scoring. Agents remember patterns, failures, and codebase structure.

src/utils/agent-memory.js

06

Cost-Aware Model Selection

Three-tier model routing: trivial (DeepSeek), standard (GLM/Kimi), complex (Anthropic Opus). Daily and monthly budget tracking.

src/utils/cost-optimizer.js

07

Documentation Agent

Generates docs, changelogs, and ADRs. Audits code comments. Stores doc structure patterns in agent memory per project.

src/agents/documentation.js

08

DevOps Agent

Pipeline monitoring, failure analysis, deployment readiness checks, and Dockerfile review. Publishes events to agent bus.

src/agents/devops.js

09

Security Agent

Parallel scans for secrets, OWASP Top 10, and dependency CVEs. Blocks MR creation on critical/high findings.

src/agents/security.js
