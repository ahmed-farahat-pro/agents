How It Works

From Task to Merge Request

Send a task before you sleep. Nigents handles the rest.

01
Send Task via Telegram
Text or voice message: "Add user authentication to the API." The Orchestrator understands intent in Arabic or English and routes it.
02
Architect Designs, Planner Breaks Down
The Architect evaluates the system design. The Planner reads your codebase via GitLab API and creates a step-by-step plan with exact file paths.
03
Agents Code in Parallel
Backend Dev and Frontend Dev work simultaneously on feature branches. DevOps sets up the pipeline. Security scans as code is written.
04
Self-Healing on Failure
If compilation fails, the agent auto-fixes and retries. If tests fail, QA reports the issue and the dev agent patches it — no human needed.
05
Review, Test, Secure
Code Reviewer audits every diff. QA Tester runs the test suite. Security performs OWASP scanning. All three must pass before proceeding.
06
Wake Up to a Merge Request
Reporter sends you a Telegram summary with MR links, test results, and security report. Approve and merge from your phone.
