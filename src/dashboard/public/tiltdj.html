What's inside

One window. Full groove box.

No DAW needed — TiltDJ runs standalone on your Mac desktop.

🥁

8 Pads + keyboard shortcuts

Kick, Snare, Hat, Clap, Bass, Riser, Chop, Horn. Click or use 1–8 and Q W E R T Y U I while you work. Toggle keyboard mode off when typing.

🎛️

Stereo pan + master vol

Separate pan sliders for pads and imported audio. 0% = full left, 50% = center, 100% = full right. Master sets the overall output level.

🔢

16-step pattern grid

An 8×16 grid — one row per pad. Toggle steps, set BPM, hit Play pattern and get a one-bar loop you can jam against your import track.

🎵

Import & remix

Drop in MP3, WAV, AIFF, M4A. Loop it, twist the speed (0.5×–1.5× time-stretch) and volume while you fire pads on top — desk-side remixing.

〰️

Waveform + hot cues

Live playhead on the import waveform. Tap to place hot cue markers and jump to any point — quick arrangement in a single click.

🎤

Voice drops (macOS speech)

Type a line or pick a preset and the app reads it aloud using native macOS speech — zero cloud, instant shout-out drops over your beat.

Install

Download & run in 30 seconds

TiltDJ ships as an unsigned DMG for local use. macOS 14 (Sonoma) or later required.

# Download from this page, then:
hdiutil attach TiltDJ-1.0.0.dmg
# Drag TiltDJ.app → Applications
# First launch: right-click → Open (Gatekeeper bypass for unsigned build)

Or just double-click the DMG, drag TiltDJ.app to Applications, and right-click → Open on first launch.
