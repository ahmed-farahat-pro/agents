What it does

Escape is a macOS menu bar app that listens for a global hotkey and instantly orchestrates your window layout to look like you've been coding all morning.

Instant window flip

One hotkey — Escape activates VS Code on your main display and Terminal on secondary. Sub-100ms switch via Accessibility API.

Configurable trigger

Set any key combo — Cmd+Shift+E, F13, a dedicated macro key. Or wire it to a Bluetooth button clipped under your desk.

Smart app roster

Choose which apps to front — VS Code, Xcode, Terminal, iTerm, Warp. Mix and match per space. The set is fully configurable.

Restore on release

Hold the hotkey and everything snaps back to exactly where you left it — windows, scroll positions, the works — when you release.

Zero footprint

Lives in the menu bar. No dock icon. No background agent. Launches at login in 8 MB of RAM. Invisible until you need it.

Fake typing mode

Optional: Escape can trigger a fake typing animation in Terminal so there's activity on screen even if you just sat down.

How it works

Three things happen in sequence when the hotkey fires.

1

Hotkey listener wakes up

A low-level CGEventTap intercepts your key combo before it reaches any app — no focus required. Escape responds even when a browser video is fullscreen.

2

Window map is taken

The current layout is snapshotted — app, space, display, bounds, z-order — so restore is exact. Snapshot takes under 5 ms via Accessibility API.

3

Target apps are fronted

VS Code (or Xcode) gets main display focus. Terminal gets the secondary. If neither is running they are launched silently. Whole sequence: ~80 ms on Apple Silicon.

Install

Open the disk image, drag Escape.app into Applications, then eject the volume.

  • On first launch, macOS will ask for Accessibility permission — required for the window manager to work.
  • If Gatekeeper blocks it: System Settings → Privacy & Security → Open anyway.
  • If needed: xattr -cr ~/Downloads/Escape-1.0.0.dmg then open again.
  • Configure your hotkey and app roster from the menu bar icon.
